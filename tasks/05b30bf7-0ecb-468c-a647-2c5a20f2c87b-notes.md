# Image upload + Buffer publishing task notes

The task URL shared in ChatGPT is a GitHub task UI link, not a GitHub issue or file endpoint accessible via the repository connector.

Goal:
- Authenticated image upload endpoint (accept multipart/form-data or raw PNG bytes).
- Validate images and enforce a safe maximum upload size.
- Store uploads in the repository only if using GitHub Contents API with base64 encoding, or use object storage and return a public HTTPS URL.
- Pass the public, directly downloadable image URL to Buffer's create post action as assets: [{ image: { url, metadata: { altText } } }].
- Keep Buffer/GitHub credentials in environment secrets; never commit secrets.
- Do not use a task endpoint's opaque task ID as a GitHub issue number or invent inaccessible task APIs.

Known integrations in this ChatGPT session:
- GitHub connector supports text file commits but no binary upload operation.
- Buffer connector supports image assets only when a direct public HTTPS image URL is already available.
